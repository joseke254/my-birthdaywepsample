# Birthday Congratulator

Welcome to the Birthday Congratulator project! This application allows users to celebrate birthdays with personalized messages, emojis, and fun confetti effects.

## Project Structure

```
birthday-congratulator
├── src
│   ├── index.html        # HTML structure for the application
│   ├── styles
│   │   └── main.css      # CSS styles for the application
│   └── scripts
│       └── main.js       # JavaScript code for user interactions
├── .github
│   └── workflows
│       └── deploy-gh-pages.yml # GitHub Actions workflow for deployment
├── .gitignore            # Files and directories to ignore by Git
├── README.md             # Project documentation
└── LICENSE               # Licensing information
```

## Features

- User-friendly form to input name and age.
- Live preview of the congratulatory message.
- Option to select an emoji and theme color.
- Confetti animation and sound effects upon submission.
- Local storage support to remember user preferences.

## Getting Started

To run the application locally, follow these steps:

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/birthday-congratulator.git
   ```

2. Navigate to the project directory:
   ```
   cd birthday-congratulator
   ```

3. Open `src/index.html` in your web browser.

## Deployment

This project is set up to be deployed on GitHub Pages. The deployment is automated using GitHub Actions. When changes are pushed to the main branch, the application will be built and deployed automatically.
